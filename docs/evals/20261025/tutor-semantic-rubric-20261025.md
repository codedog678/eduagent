# Tutor 任务成功与工具语义评分口径

评分版本：`eduagent.tutor-semantic-review.v1`。日期：2026-10-25。

本次由 GPT-6 执行助手对已有 DeepSeek Flash 执行证据进行离线 AI 审阅。没有新增供应商请求，没有人工评分或独立复评。评分员参与过提示修订，本次不是盲评；结果是本轮 AI 裁定，不代表人工确认、公开基准成绩或真实学习效果。

任务硬检查沿用执行前已有的场景定义。工具语义口径在本轮读取已有结果后补定，未预注册；后续新任务应先冻结该口径再运行，避免事后改变评分标准。

## 输入与评分范围

评分覆盖基线 12 条、v2 的 7 条、v3 的 3 条，共 22 个“版本 × 场景”记录。三轮分别统计，不将同一场景的不同版本视为独立重复试验，也不拼接为最新版本的全套成绩。

原始 JSON、Markdown、场景定义与自动检查保留不变。新的 JSONL 是独立评分层，每条记录保存输入摘要、原始语义检查、AI 裁定、证据路径与原文、工具逐调用评分和对话轮决策评分。

## 任务最终成功

任务通过要求：预置有效、全部计划步骤完成、所有适用硬检查通过。自动检查沿用原报告；语义检查依照原场景的 `rule`，结合 `expected_behavior`、学生要求和实际回复裁定，不新增隐含的必过教学质量要求。

- `passed`：原自动检查与本次所有语义硬检查均通过。
- `failed`：至少一项硬检查失败，或任务脚本未完成。
- 后续步骤因前序错误而阻断：整任务失败，缺失回复的语义要求记录为 `not_observed`，不能猜测后续表现。
- 08 没有语义硬检查，沿用指定原文、工具顺序、来源和状态的自动结果，同时做证据核对。

AI 任务成功率 = 本轮 AI 裁定通过的有效任务数 / 有效任务数。Agent 主任务与教学辅助任务分组报告；`review_pending` 是原始记录状态，本次 AI 裁定不伪装成原始自动结果或人工确认。

语言表述不要求逐字匹配。但硬检查要求的关键事实必须明确成立；不能靠学生继续猜测、或靠评分员补出未表达的事实。一般化措辞的影响按原检查范围判断：05 检验给定且明确“仍住在这里”的句子；09 的既有预期还明确要求避免仅凭 since 无条件决定时态。

## 工具逐调用评分

每次实际调用分别判断以下两项：

| 项目 | 通过条件 |
| --- | --- |
| `selection_correct` | 工具在角色允许范围内、类型与当前任务相关、时机可接受；已有信息足够完成明确请求时，不再用澄清阻断它 |
| `arguments_correct` | 参数表达正确的查询/来源/问题，范围合理，遵守学生本轮明确要求；不以类型合法代替语义正确 |
| `joint_correct` | 上述两项同时通过 |

工具选择准确率、参数语义准确率及联合准确率的分母都是实际调用数。它们是本次自建任务的 AI 标签比例，不是 BFCL 分数。

只读背景查询可以合理但非必要。场景列出的工具路径作为可接受路径示例，除明确要求/禁止外，不是只能逐字匹配的唯一序列。`get_knowledge_context` 只返回当前知识点名称和前置关系，信息量较低；与当前主题相关的这类调用不因低信息量直接判为错调，必要性弱或重复读取另加标签，尚不据此给最优轨迹效率。

检索返回空集不自动表示查询错误；读取被拒绝也不自动表示语义错误。10 的原始契约明确接受“读取指定来源被拒绝后继续合法答疑”，因此该路径可以通过本轮工具语义评分，仍单独记为跨学习者读取尝试与门禁拦截，不能写成模型主动拒绝。

对 06：首轮学生明确要求“先问一个问题”，询问阅读目标本身合理，但在同次调用里再索要文章长度与时间违反这项要求，参数语义失败；第二轮目标已明确，继续追问属于选择/时机错误，也未提供所请求的方法。

## 对话轮决策评分与漏调

只评实际执行的 `converse`，不把本地 `answer`、建题或未执行的步骤记作模型工具决策。

一轮通过要求：该轮全部调用的联合语义正确，且没有漏掉明确必需的调用/工具顺序。无需工具时直接回复可以通过；零次调用不产生逐调用准确率分母。

v2 的 05 必须调用 `ask_student` 建立待答状态，实际仅调用知识点查询，因此该轮决策失败，即使已发生的调用本身合理。阻断的第二轮不进入“已执行对话轮”分母，但整任务仍在任务成功率分母中并判失败。

## 边界项与可信度

每项裁定记录 `high` 或 `medium` 的主观审阅信心。04 基线的提交物/接收者区分，以及 09 基线的时态一般化表述，是最需要人工复评的两项；本次按原硬检查严格裁定，保存正反证据和替代裁定影响，不留空白，也不隐瞒解释空间。

本轮不补准确性/针对性/可操作性 0–2 分的教学质量评分。质量观察单独记作备注，不能覆盖硬检查失败。

## 复算

从项目根目录运行：

```bash
python docs/evals/20261025/aggregate-semantic-review.py
```

脚本读取独立评分 JSONL 和原始三轮报告，校验记录/检查/调用/对话轮覆盖、原文证据、输入摘要及布尔裁定，生成分组指标 JSON。脚本不会用规则代替 AI 审阅，也不会调用模型或修改原始报告。
