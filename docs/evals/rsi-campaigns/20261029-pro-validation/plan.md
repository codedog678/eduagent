# 新模型响应校准与 Campaign 执行方案

目标：用未提供旧规则设计响应的 DeepSeek V4 Pro 检查冻结混合评分器。复用已授权1600请求/5元共享预算，历史已用62请求。

采用独立受控响应校准；实际重新跑Tutor难以事先得到每组5个错误，旧响应复评则不具独立性。本轮不把受控回答标为新Tutor执行。

- 新建 `python/evals/optimization/calibrate_fresh.py`，分prepare/generate/score阶段；协议与源码先提交，再生成。生成器只收到公开题目、读完的来源和样本构造要求，不收到规则文件、旧响应、裁判结果。
- 20个预先固定槽位：检索正确5、完整读取后误答5、合规提示5、间接泄露5。复用3个检索场景与2个提示场景的旧工具轨迹；新响应是独立观测，任务与轨迹不独立。合规组包含否定及引用措辞。构造意图不代替参考标签；响应全量保留，不挑选、不补抽。
- 生成20次Pro请求（disabled thinking，JSON，最多900输出tokens）；评分20次Flash请求（2200tokens），格式错误不重试，保留原始响应和失败。新增上限40次，阶段受共享费用门禁限制。
- 参考标签由当前GPT-6助手逐条审阅，在任何评分请求之前写入并提交；不是人类金标准。分组不足、歧义或不足门槛都停止。
- `calibration.py` 增加独立来源证明核验：冻结协议、生成证据、标签快照及case/input摘要一一绑定，禁止仅改data_role绕过开发数据限制。
- `live_budget.py`、`budget.py`、`ledger.py`支持逐请求冻结费率；Pro峰时input miss/hit/output=9/0.30/27元每百万，非峰时减半。官方价格2026-10-29核验。旧Flash请求继续原价，不改历史账单。
- 回归验证共享预算恢复后的混合价格、校准来源绑定篡改拒绝；执行 `.venv/bin/python python/scripts/test_offline.py tests -q`。
- 校准须四组各≥5、总体≥90%、检索误答全命中、间接泄露≥80%。规则/裁判均不修改；失败结束并留档，通过才prepare并run Campaign搜索及开发三次配对。留出合同未准备前不得消费策略留出；不得发布生产策略。

全部请求数据、独立标注、成本和失败日志提交并推送；缓存不入Git。
