## 3.3 前端目录详解（frontend/src/）

```
frontend/src/
├── main.tsx                      # React入口：ReactDOM.createRoot
├── App.tsx                       # 主组件：学习流程 + 数据分析两个Tab
├── components/
│   ├── AnalyticsDashboard.tsx    # 数据看板：统计/分布/薄弱点/曲线
│   └── ReviewReminder.tsx        # 复习提醒：轮询/保留度/紧急度

    └── useWebSocket.ts           # WebSocket Hook：连接/重连/去重
```

| 文件 | 职责 |
|---|---|
| `main.tsx` | 挂载React根组件 |
| `App.tsx` | 主界面：知识选择、出题、答题、反馈、事件流 |
| `AnalyticsDashboard.tsx` | 统计卡片、知识分布柱状图、薄弱点列表、学习曲线 |
| `ReviewReminder.tsx` | 30秒轮询复习计划、保留度仪表盘、紧急度标签 |
| `useWebSocket.ts` | 指数退避重连、事件去重、按批次分组 |

## 3.4 文件间调用关系

### 核心调用链

```
api/main.py
  └── api/orchestrator.py
        ├── agents/assessment_agent.py → core/learner_model.py (BKT)
        ├── agents/tutor_agent.py → core/llm_service.py → llm/factory.py
        ├── agents/curriculum_agent.py → core/spaced_repetition.py (SM-2)
        │                              → core/knowledge_graph.py (DAG)
        ├── agents/engagement_agent.py → 纯逻辑（无外部依赖）
        │
        ├── core/event_bus.py          ← 4个Agent共享的事件总线
        │
        ├── models/database.py         ← ORM定义
        ├── models/session.py          ← 数据库连接
        └── repositories/*.py          ← 数据读写
```

### 数据流向

```
前端 App.tsx
  │ fetch() / WebSocket
  ▼
api/routes.py 或 api/websocket.py
  │
  ▼
api/orchestrator.py
  │ publish_root_event()
  ▼
core/event_bus.py
  │ distribute to subscribers
  ▼
agents/*.py
  │ 处理事件 → 调用 core/ 算法
  │ publish result events
  ▼
repositories/*.py → models/database.py → PostgreSQL
  │
  ▼
返回 InteractionResult 给前端
```

## 3.5 如何快速定位代码

| 我想看... | 去哪个文件 |
|---|---|
| 事件怎么定义的 | `core/event_bus.py` → `EventType` 枚举 |
| BKT算法怎么算的 | `core/learner_model.py` |
| SM-2怎么调度复习 | `core/spaced_repetition.py` |
| 知识图谱有哪些知识点 | `core/knowledge_graph.py` → `ENGLISH_KNOWLEDGE_GRAPH` |
| Agent怎么订阅事件 | `agents/base.py` → `register()` |
| 某个Agent的具体逻辑 | `agents/xxx_agent.py` → `handle_event()` |
| LLM怎么选提供商 | `llm/factory.py` → `get_llm()` |
| API端点有哪些 | `api/routes.py` + `api/v1/` |
| 数据库表结构 | `models/database.py` |
| 请求怎么编排Agent | `api/orchestrator.py` |
| 前端怎么显示结果 | `frontend/src/App.tsx` |

## 3.6 汇报要点

**讲这部分时可以这样说**：

> "项目采用**分层架构**，后端分为6层：
> - **接口层**（api/）：接收请求，编排Agent
> - **智能体层**（agents/）：4个Agent自主处理事件
> - **核心引擎层**（core/）：BKT、SM-2、知识图谱等算法
> - **业务逻辑层**（services/）：轻量封装
> - **数据访问层**（repositories/）：CRUD操作
> - **持久层**（models/）：ORM定义
>
> 前端只有4个文件，极度精简，核心是App主组件 + 2个子组件 + 1个WebSocket Hook。
>
> **关键设计**：Agent层和核心引擎层是系统的价值核心，其他层都是为之服务的基础设施。"
