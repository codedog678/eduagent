## 5.1 BKT 贝叶斯知识追踪

### 教育技术学背景

**什么是BKT？**

贝叶斯知识追踪（Bayesian Knowledge Tracing）由 Corbett & Anderson 于 1995 年提出，是智能教学系统（ITS）中最经典的学习者建模算法。核心思想是：

> **学生对知识点的掌握程度是一个隐变量（latent variable），我们无法直接观测，只能通过答题表现来推断。**

BKT 用贝叶斯公式，根据每次答题的对/错，不断更新"学生已学会"这一隐变量的概率估计。

**与相关理论的关系**：

| 理论 | 核心思想 | 与BKT的关系 |
|---|---|---|
| **行为主义** | 学习=刺激-反应的强化 | BKT的P(T)模拟了"练习导致学会"的强化过程 |
| **认知主义** | 学习=知识状态的内在变化 | BKT追踪的就是内在知识状态（mastery） |
| **建构主义** | 学习=主动建构知识 | BKT本身不建模建构过程，但可以作为上层算法的输入 |
| **掌握学习理论**（Bloom） | 所有学生都能掌握，只是需要不同时间 | BKT的 mastery 概率就是"已掌握"的量化估计 |

**BKT vs IRT vs Deep Knowledge Tracing**：

| 方法 | 时期 | 特点 | 本项目选择 |
|---|---|---|---|
| BKT | 1995 | 参数少、可解释、计算快 | ✅ 选用 |
| IRT（项目反应理论） | 1968 | 静态模型，评估题目难度而非学习过程 | 不适用 |
| DKT（深度知识追踪） | 2015 | 用LSTM建模，需要大量数据 | 数据量不足，不适用 |

### 四个核心参数

```
┌─────────────────────────────────────────────────────────┐
│                    BKT 状态转移模型                       │
│                                                          │
│    ┌─────────┐    P(T)     ┌─────────┐                  │
│    │  未学会  │ ─────────▶ │  已学会  │                  │
│    │  (¬L)   │             │   (L)   │                  │
│    └────┬────┘             └────┬────┘                  │
│         │                       │                        │
│    答题表现                  答题表现                      │
│         │                       │                        │
│    ┌────▼────┐             ┌────▼────┐                  │
│    │P(G)猜对 │             │P(S)失误 │                  │
│    └─────────┘             └─────────┘                  │
└─────────────────────────────────────────────────────────┘
```

| 参数 | 符号 | 默认值 | 含义 | 直觉解释 |
|---|---|---|---|---|
| **初始掌握概率** | P(L₀) | 0.1 | 学生一开始就会的概率 | "大多数人开始时不会" |
| **学习转移概率** | P(T) | 0.15 | 每次练习后学会的概率 | "每次练习有15%机会突然开窍" |
| **猜测概率** | P(G) | 0.2 | 不会但猜对的概率 | "4个选项有20%概率蒙对" |
| **失误概率** | P(S) | 0.1 | 会了但答错的概率 | "10%的概率粗心写错" |

### 代码实现详解

文件：`core/learner_model.py`

#### 1. 知识状态数据结构

```python
class KnowledgeState(BaseModel):
    """单个知识点的掌握状态。"""
    knowledge_id: str
    mastery: float = 0.1       # P(L) 当前掌握概率
    alpha: float = 1.0         # Beta分布 α = 成功次数 + 1
    beta: float = 9.0          # Beta分布 β = 失败次数 + 1
    attempts: int = 0          # 总尝试次数
    correct_count: int = 0     # 答对次数
    streak: int = 0            # 连续正确次数
```

**为什么用 Beta 分布？**

Beta 分布是"概率的概率"——它描述的是对一个概率值的不确定性。

```
Beta(α=1, β=9) 的分布：
  │
  │  ████
  │  ██████
  │  ████████
  │  ██████████
  │  ████████████
  │  ██████████████
  └──────────────────── 0 ──── 0.5 ──── 1.0
                          mastery

初始状态：α=1, β=9 → 期望值 = 1/(1+9) = 0.1
答对一次：α=2, β=9 → 期望值 = 2/(2+9) = 0.182
答对两次：α=3, β=9 → 期望值 = 3/(3+9) = 0.25
```

**置信度计算**：

```python
@property
def confidence(self) -> float:
    """置信度：数据越多，置信度越高。"""
    total = self.alpha + self.beta
    return min(1.0, total / 20.0)
```

- 答题 0 次：confidence = 1/20 = 0.05（几乎不确定）
- 答题 10 次：confidence = 11/20 = 0.55（半信半疑）
- 答题 19 次：confidence = 20/20 = 1.0（完全确信）

#### 2. BKT 核心更新算法

```python
def update_mastery(self, knowledge_id: str, is_correct: bool) -> KnowledgeState:
    """
    BKT 核心：贝叶斯更新 + 学习转移。

    数学推导：
      答对时：
        P(correct|L) = 1 - P(S)     # 会了且没失误
        P(correct|¬L) = P(G)         # 不会但猜对
        P(L|correct) = P(L)×(1-P(S)) / P(correct)

      答错时：
        P(wrong|L) = P(S)            # 会了但失误
        P(wrong|¬L) = 1 - P(G)      # 不会且没猜对
        P(L|wrong) = P(L)×P(S) / P(wrong)
    """
    state = self.get_state(knowledge_id)
    p_l = state.mastery

    # 1. 根据对/错选择似然函数
    if is_correct:
        p_obs_given_l = 1 - self.bkt.p_slip       # P(correct|L) = 1 - 0.1 = 0.9
        p_obs_given_not_l = self.bkt.p_guess       # P(correct|¬L) = 0.2
        state.correct_count += 1
        state.streak += 1
        state.alpha += 1                            # Beta分布更新
    else:
        p_obs_given_l = self.bkt.p_slip            # P(wrong|L) = 0.1
        p_obs_given_not_l = 1 - self.bkt.p_guess   # P(wrong|¬L) = 0.8
        state.streak = 0
        state.beta += 1

    # 2. 贝叶斯更新：P(L|obs) = P(L)×P(obs|L) / P(obs)
    p_obs = p_l * p_obs_given_l + (1 - p_l) * p_obs_given_not_l
    p_l_given_obs = (p_l * p_obs_given_l) / p_obs if p_obs > 0 else p_l

    # 3. 学习转移（关键设计！）
    if is_correct:
        # 答对：后验 + 转移（"练习可能学会"）
        p_l_new = p_l_given_obs + (1 - p_l_given_obs) * self.bkt.p_transit
    else:
        # 答错：仅后验，不转移
        # ⚠️ 这是产品设计决策，不是原始BKT公式
        p_l_new = p_l_given_obs

    state.mastery = max(0.0, min(1.0, p_l_new))
    state.attempts += 1
    return state
```

#### 3. 关键设计决策：答错不转移

```python
# 原始BKT公式（理论版）：
# 无论对错都加学习转移：
# P(Lₙ) = P(Lₙ|obs) + (1 - P(Lₙ|obs)) × P(T)

# 本项目的修正（产品版）：
if is_correct:
    p_l_new = p_l_given_obs + (1 - p_l_given_obs) * self.bkt.p_transit
else:
    p_l_new = p_l_given_obs  # ❌ 不加转移
```

**为什么？**

> 答错一次反而 mastery 上升，在数学上是合理的（贝叶斯后验确实可能上升），
> 但对用户来说**反直觉**——"我答错了，掌握度怎么还涨了？"
>
> 所以产品上选择：答错时只做后验更新，不加学习转移。

#### 4. 遗忘曲线

```python
def get_forgetting_curve(self, knowledge_id: str, days_since_last_review: float) -> float:
    """
    艾宾浩斯遗忘曲线：R = e^(-t/S)

    R: 记忆保持率 (0-1)
    t: 距离上次复习的时间（天）
    S: 记忆强度（与mastery和streak正相关）
    """
    state = self.get_state(knowledge_id)

    # 记忆强度 = mastery × (1 + streak × 0.1)
    # 连续答对越多，记忆越牢固
    memory_strength = state.mastery * (1 + state.streak * 0.1)
    memory_strength = max(0.1, memory_strength)  # 防止除零

    retention = 2.71828 ** (-days_since_last_review / memory_strength)
    return max(0.0, min(1.0, retention))
```

**遗忘曲线的实际效果**：

| mastery | streak | 记忆强度S | 1天后保持率 | 3天后保持率 | 7天后保持率 |
|---|---|---|---|---|---|
| 0.3 | 0 | 0.30 | 3.6% | 0.0% | 0.0% |
| 0.6 | 2 | 0.72 | 25.0% | 1.5% | 0.0% |
| 0.85 | 5 | 1.275 | 45.8% | 9.6% | 0.9% |
| 0.95 | 8 | 1.71 | 56.1% | 17.7% | 3.1% |

→ 掌握度越高、连续正确越多，遗忘越慢

## 5.2 SM-2 间隔重复算法

### 教育技术学背景

**什么是间隔重复？**

间隔重复（Spaced Repetition）基于**间隔效应**（Spacing Effect）：

> **将学习分散在多个时间段，比集中突击（cramming）效果更好。**

这是认知心理学中最稳健的发现之一（Ebbinghaus, 1885；Cepeda et al., 2006）。

**SM-2 算法的来历**：

SuperMemo 是第一个将间隔效应工程化的软件（Wozniak, 1990）。SM-2 是其第二版算法，被 Anki、Quizlet 等主流记忆软件广泛采用。

**与其他记忆系统的对比**：

| 系统 | 间隔策略 | 特点 |
|---|---|---|
| **Leitner 盒子** | 5个盒子，答对升级，答错降级 | 离散分级，简单直观 |
| **SM-2** | 连续调整 EF 因子 | 连续调整，更精细 |
| **FSRS**（2023） | 用机器学习预测最优间隔 | 最先进，但需要大量数据 |
| **本项目 SM-2** | 标准 SM-2 + BKT 遗忘曲线 | SM-2 调度 + BKT 预测遗忘 |

### 代码实现详解

#### 1. 复习条目数据结构

```python
class ReviewItem(BaseModel):
    knowledge_id: str
    easiness_factor: float = 2.5    # EF因子 [1.3, 2.5]
    interval_days: float = 0         # 当前间隔（天）
    repetition: int = 0              # 成功复习次数
    next_review: datetime            # 下次复习时间
    last_review: datetime | None     # 上次复习时间
    total_reviews: int = 0           # 总复习次数

    @property
    def is_due(self) -> bool:
        return datetime.now() >= self.next_review
```

#### 2. SM-2 核心算法

```python
def review(self, item: ReviewItem, quality: int) -> ReviewItem:
    """
    SM-2 核心：根据回答质量更新复习计划。

    quality: 0-5
        5 = 完美回答，毫不犹豫
        4 = 正确，但需要思考
        3 = 正确，但很困难
        2 = 错误，但看到答案觉得熟悉
        1 = 错误，看到答案才有印象
        0 = 完全不会
    """
    quality = max(0, min(5, quality))
    item.total_reviews += 1
    item.last_review = datetime.now()

    # 步骤1：更新 EF（难度因子）
    # 公式：EF' = EF + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))
    new_ef = item.easiness_factor + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
    item.easiness_factor = max(1.3, min(2.5, new_ef))

    # 步骤2：计算间隔
    if quality < 3:
        # 回答质量太低，重置从头复习
        item.repetition = 0
        item.interval_days = 1
    else:
        if item.repetition == 0:
            item.interval_days = 1     # 第1次：1天后
        elif item.repetition == 1:
            item.interval_days = 6     # 第2次：6天后
        else:
            # 之后：interval = 上次interval × EF
            item.interval_days = item.interval_days * item.easiness_factor
        item.repetition += 1

    # 步骤3：设置下次复习时间
    item.next_review = datetime.now() + timedelta(days=item.interval_days)
    return item
```

#### 3. EF 因子变化规律

| quality | EF变化 | 效果 |
|---|---|---|
| 5（完美） | EF + 0.10 | 间隔增长最快 |
| 4（正确） | EF + 0.00 | 间隔不变 |
| 3（困难） | EF - 0.08 | 间隔增长变慢 |
| 2（错误） | EF - 0.24 | 重置间隔 |
| 1（不会） | EF - 0.40 | 重置间隔 |
| 0（完全不会） | EF - 0.56 | 重置间隔 |

**EF 的物理意义**：
- EF = 2.5：每次间隔翻 2.5 倍（增长很快，说明很容易）
- EF = 1.3：每次间隔只增长 30%（增长很慢，说明很难）
- EF < 1.3 会被强制设为 1.3（防止间隔缩短）

#### 4. 间隔增长示例

假设学生每次都回答 quality=4（正确但需思考），EF 保持 2.5：

| 复习次数 | 间隔（天） | 累计天数 |
|---|---|---|
| 第1次 | 1 | 1 |
| 第2次 | 6 | 7 |
| 第3次 | 6 × 2.5 = 15 | 22 |
| 第4次 | 15 × 2.5 = 37.5 | 60 |
| 第5次 | 37.5 × 2.5 = 93.75 | 154 |
| 第6次 | 93.75 × 2.5 = 234 | 388 |

→ 从1天到234天，约6次复习后几乎永久记住

## 5.3 知识图谱 DAG

### 教育技术学背景

**什么是知识图谱？**

在教育领域，知识图谱（Knowledge Graph）表示知识点之间的**依赖关系**。它是一个 DAG（有向无环图）：

> **要学习知识点B，必须先掌握知识点A（如果A是B的前置知识）。**

**理论基础**：

| 理论 | 核心思想 | 在知识图谱中的体现 |
|---|---|---|
| **先决条件学习**（Gagné） | 学习新知识需要先掌握先决条件 | 边 = 先决条件依赖 |
| **最近发展区**（Vygotsky） | 学习应该在"跳一跳够得着"的范围内 | `get_ready_nodes()` 推荐就绪节点 |
| **认知负荷理论**（Sweller） | 同时学习过多内容会导致认知过载 | 拓扑排序确保一次只学一个新概念 |
| **知识空间理论**（Doignon） | 知识状态是已掌握知识点的子集 | `mastered_ids` 就是当前知识状态 |

**知识图谱 vs 知识树 vs 知识列表**：

| 结构 | 特点 | 局限 |
|---|---|---|
| **列表** | 简单，无序 | 无法表示依赖 |
| **树** | 有层级，单父节点 | 一个知识点不能有两个前置 |
| **图（DAG）** | 灵活，多前置、多后继 | ✅ 最接近真实知识结构 |

### 代码实现详解

文件：`core/knowledge_graph.py`

#### 1. 数据结构

```python
class KnowledgeNode(BaseModel):
    id: str                    # 知识点ID
    name: str                  # 显示名称
    subject: str = "math"      # 学科
    difficulty: float = 0.5    # 难度 0-1
    description: str = ""      # 描述
    prerequisites: list[str]   # 前置知识点ID列表
    tags: list[str]            # 标签

class KnowledgeGraph:
    def __init__(self):
        self.nodes: dict[str, KnowledgeNode] = {}
        self._adjacency: dict[str, list[str]] = {}    # 后继节点
        self._reverse_adj: dict[str, list[str]] = {}  # 前置节点
```

#### 2. Kahn 拓扑排序

```python
def topological_sort(self) -> list[str]:
    """
    Kahn算法拓扑排序：确保前置知识排在前面。

    时间复杂度：O(V + E)
    """
    # 1. 计算入度
    in_degree: dict[str, int] = {nid: 0 for nid in self.nodes}
    for nid in self.nodes:
        for succ in self._adjacency.get(nid, []):
            if succ in in_degree:
                in_degree[succ] += 1

    # 2. 将入度为0的节点入队
    queue = deque([nid for nid, deg in in_degree.items() if deg == 0])
    result: list[str] = []

    # 3. BFS处理
    while queue:
        nid = queue.popleft()
        result.append(nid)
        for succ in self._adjacency.get(nid, []):
            if succ in in_degree:
                in_degree[succ] -= 1
                if in_degree[succ] == 0:
                    queue.append(succ)

    # 4. 环检测
    if len(result) != len(self.nodes):
        logger.warning("Knowledge graph contains a cycle!")

    return result
```

#### 3. 就绪节点检测（核心方法）

```python
def get_ready_nodes(self, mastered_ids: set[str]) -> list[str]:
    """
    获取当前可以学习的知识点：
    前置知识全部掌握，但自己还未掌握。

    这是 Curriculum Agent 推荐下一个知识点的核心逻辑。
    """
    ready = []
    for nid, node in self.nodes.items():
        if nid in mastered_ids:
            continue                           # 已掌握，跳过
        prereqs = set(node.prerequisites)
        if prereqs.issubset(mastered_ids):     # 前置条件全部满足
            ready.append(nid)
    return sorted(ready, key=lambda nid: self.nodes[nid].difficulty)
```

**就绪节点判定逻辑**：

```
学生已掌握: {vocab_basic, grammar_tenses}

检查 grammar_passive:
  prerequisites = {grammar_tenses}
  {grammar_tenses} ⊂ {vocab_basic, grammar_tenses} ✅
  → grammar_passive 是就绪节点

检查 grammar_relative:
  prerequisites = {grammar_tenses, vocab_intermediate}
  {grammar_tenses, vocab_intermediate} ⊄ {vocab_basic, grammar_tenses} ❌
  → grammar_relative 不是就绪节点（vocab_intermediate未掌握）

检查 vocab_advanced:
  prerequisites = {vocab_intermediate}
  {vocab_intermediate} ⊄ {vocab_basic, grammar_tenses} ❌
  → vocab_advanced 不是就绪节点
```

#### 4. 学习路径规划

```python
def get_learning_path(self, target_id: str, mastered_ids: set[str]) -> list[str]:
    """
    生成到达目标知识点的最短学习路径。
    从target反向遍历，找出所有未掌握的前置知识，按拓扑序排列。
    """
    needed = self.get_all_prerequisites(target_id) - mastered_ids
    if target_id not in mastered_ids:
        needed.add(target_id)

    full_order = self.topological_sort()
    return [nid for nid in full_order if nid in needed]
```

**路径规划示例**：

```
目标：学习 writing_essay（议论文写作）
已掌握：{vocab_basic, grammar_tenses}

依赖链：
  writing_essay → writing_paragraph → grammar_tenses ✅
  writing_essay → writing_paragraph → vocab_intermediate ❌
  writing_essay → grammar_relative → grammar_tenses ✅
  writing_essay → grammar_relative → vocab_intermediate ❌

需要学习：{vocab_intermediate, writing_paragraph, grammar_relative, writing_essay}

拓扑排序后：vocab_intermediate → writing_paragraph → grammar_relative → writing_essay
```

## 5.4 三个算法如何协同工作

### 协同流程

```
学生提交答案
    │
    ▼
┌─────────────────────────────────────────────────┐
│ 1. AssessmentAgent 调用 BKT                      │
│    update_mastery(knowledge_id, is_correct)      │
│    → 输出: mastery变化、错误模式                   │
└──────────────────────┬──────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────┐
│ 2. CurriculumAgent 调用 SM-2 + 知识图谱           │
│    SM-2: review(item, quality) → 更新复习计划     │
│    知识图谱: get_ready_nodes(mastered) → 推荐下一个│
│    遗忘曲线: get_forgetting_curve() → 预测遗忘    │
│    → 输出: 下一知识点、复习提醒                    │
└──────────────────────┬──────────────────────────┘
                       │
                       ▼
┌─────────────────────────────────────────────────┐
│ 3. TutorAgent 调用 LLM                           │
│    根据 mastery 等级选择提示策略                   │
│    BEGINNER → 脚手架提示                          │
│    DEVELOPING → 苏格拉底式提问                    │
│    PROFICIENT → 引导式提示                        │
│    → 输出: 教学回复、3级提示                       │
└─────────────────────────────────────────────────┘
```

### 数据流转

```
BKT mastery ──→ 知识图谱 get_ready_nodes() ──→ 推荐下一知识点
     │                                              │
     │                                              ▼
     │                                    SM-2 review() ──→ 复习计划
     │
     ▼
  掌握度等级 ──→ TutorAgent 提示策略选择
     │
     ▼
  遗忘曲线 ──→ CurriculumAgent 复习提醒
```

### 具体示例

```
场景：学生答错了一道"时态"题

1. BKT 更新：
   mastery: 0.35 → 0.28（答错，仅后验更新）
   streak: 2 → 0（连续正确中断）
   level: DEVELOPING → DEVELOPING（还在发展区）

2. SM-2 更新：
   quality = 1（错误，看到答案才有印象）
   EF: 2.5 → 2.18（难度因子降低）
   interval_days: 6 → 1（重置间隔，1天后复习）
   next_review: 明天

3. 知识图谱：
   mastered_ids 中没有 "grammar_tenses"
   ready_nodes = ["grammar_tenses", "vocab_basic"]（假设这两个就绪）
   → 推荐继续练习时态，或先巩固基础词汇

4. TutorAgent：
   mastery = 0.28 → BEGINNER 等级
   → 选择脚手架提示："先看时间线索，再判断动作时态"
```

## 5.5 汇报要点

**讲这部分时可以这样说**：

> "系统的智能核心由三个经典教育技术算法构成：
>
> **1. BKT（贝叶斯知识追踪）**：每次答题后，用贝叶斯公式更新学生对知识点的掌握概率。我们做了一个产品优化——答错时不加学习转移，避免'答错反而涨掌握度'的反直觉表现。
>
> **2. SM-2（间隔重复）**：根据回答质量动态调整复习间隔。答得好的间隔越来越长（1天→6天→15天→37天...），答得差的重置回1天。这就是 Anki 背单词的核心算法。
>
> **3. 知识图谱（DAG）**：用拓扑排序确定学习顺序，用就绪节点检测推荐下一个可学的知识点。我们内置了37个英语知识点，覆盖词汇、语法、阅读、写作、听力、口语7个维度。
>
> 三个算法的协同：BKT告诉系统'学生现在会什么'，知识图谱告诉系统'接下来该学什么'，SM-2告诉系统'什么时候复习'。"

## 5.7 当前实现的不足与改进方向

### 一、BKT 算法层面

| 不足 | 现状 | 理论差距 | 改进方向 |
|---|---|---|---|
| **参数全局固定** | P(L0)=0.1, P(T)=0.15, P(G)=0.2, P(S)=0.1 对所有学生统一 | 认知差异：不同学生的猜测能力、失误率差异很大 | 按学生/知识点个性化调参（Individualized BKT） |
| **缺少遗忘参数 P(F)** | 原始BKT有P(F)表示"学会后又忘记"的概率，本项目未实现 | 遗忘是真实学习中的核心现象 | 加入P(F)参数，与遗忘曲线联动 |
| **答错不加转移是妥协** | 产品决策：答错时只用后验，不加P(T) | 原始BKT理论认为每次交互都可能触发学习 | 可考虑"答错但接近正确"时加小概率转移 |
| **单次更新无时序** | 每次答题独立更新，不考虑答题间隔 | 间隔效应：同样答对10次，分散在7天比集中1小时效果好 | 引入时间衰减因子 |
| **无多维建模** | mastery是单一概率值 | 知识有多个维度（程序性/陈述性/元认知） | 可扩展为多维BKT |

### 二、SM-2 间隔重复层面

| 不足 | 现状 | 理论差距 | 改进方向 |
|---|---|---|---|
| **quality 需手动输入** | 当前quality参数由调用者提供，非自动计算 | 实际系统应根据答题表现自动推断quality | 结合BKT的mastery变化自动推断quality |
| **不考虑记忆强度** | SM-2只看EF和间隔，不考虑当前mastery | 遗忘曲线表明记忆强度影响复习效果 | SM-2 + 遗忘曲线联合调度 |
| **EF范围固定** | [1.3, 2.5]对所有知识点统一 | 不同难度的知识点EF变化应不同 | 按知识点难度动态调整EF范围 |
| **无难度感知** | 同等quality下，难题和简单题的EF变化相同 | 难题答对比简单题答对更有价值 | 加权EF更新 |
| **无复习上限** | 理论上间隔可以无限增长 | 长期记忆也需要周期性强化 | 设置最大间隔（如180天）后强制复习 |

### 三、知识图谱层面

| 不足 | 现状 | 理论差距 | 改进方向 |
|---|---|---|---|
| **静态图谱** | 37个节点，手动定义，不随学习变化 | 专家知识图谱应该是动态演化的 | 支持动态添加节点和边 |
| **无边权重** | 所有前置关系权重相同 | 有些前置知识比其他更重要 | 添加边权重，影响路径推荐 |
| **无学习时间估算** | 不知道每个知识点需要多少时间 | 教学设计需要时间预估 | 添加expected_minutes字段 |
| **规模有限** | 英语37节点，数学20节点 | 真实英语学习需要数百个知识点 | 扩展图谱规模，或支持自动构建 |
| **无横向关联** | 只有纵向依赖，缺少跨维度关联 | 词汇和语法是相互促进的 | 添加"促进"类型的边 |
| **无适应性路径** | 路径推荐只看前置是否满足 | 不同学生适合不同学习顺序 | 基于mastery的个性化路径 |

### 四、三算法协同层面

| 不足 | 现状 | 改进方向 |
|---|---|---|
| **BKT与SM-2未联动** | BKT的mastery和SM-2的EF是独立的 | mastery高→EF增长快，mastery低→EF增长慢 |
| **遗忘曲线未用于调度** | `get_forgetting_curve()`计算了但未实际用于复习调度 | 当预测保持率低于阈值时自动触发复习 |
| **无学习效果评估** | 不知道算法是否真的有效 | 需要A/B测试框架，对比有/无算法的学习效果 |
| **无冷启动处理** | 新学生从0.1开始，无先验知识 | 可通过入学测试快速定位初始mastery |

### 五、LLM 服务层面

| 不足 | 现状 | 改进方向 |
|---|---|---|
| **题库覆盖不全** | 只有6个知识点有题库（vocab_basic/intermediate, grammar_tenses/passive, reading_skimming, writing_paragraph） | 扩展到所有37个知识点 |
| **模板降级质量有限** | 无LLM时用关键词匹配生成回复 | 模板库需要更丰富，覆盖更多场景 |
| **无响应缓存** | 相同prompt每次都要调LLM | 添加语义缓存，减少API调用 |
| **无成本控制** | 没有token使用统计和限制 | 添加预算控制，防止API费用超支 |
| **Prompt无版本管理** | prompt散落在代码中 | 抽取为配置文件，支持A/B测试 |

### 六、系统工程层面
